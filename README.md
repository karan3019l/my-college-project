# SchemeMatch

SchemeMatch is a college micro project based on government schemes.

The website helps users find schemes and check basic eligibility
and document requirements.

## Features

- Find schemes
- Search schemes
- Check eligibility
- View required documents
- View scheme details
- Simple and responsive design

## Technologies Used

HTML  
CSS  
JavaScript  
JSON

## Project Files

- index.html – Home page
- find-schemes.html – Scheme search
- results.html – Search results
- scheme-details.html – Scheme information
- script.js – Website functionality
- style.css – Website design
- schemes_data.json – Scheme data

## Project Purpose

This project is developed as part of a college micro project
to demonstrate a simple web-based scheme discovery system.

## Note

This is an educational project. The information shown on the
website is for demonstration purposes.
